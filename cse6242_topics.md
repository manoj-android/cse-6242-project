# CSE 6242: Technologies & Techniques

## Technologies & Tools

* **SQLite** – Relational database and embedded SQL query engine
* **Git** – Version control system and code backup management
* **D3.js** – Interactive, web-based SVG/HTML/Canvas data visualization library
* **Apache Hadoop** – Distributed storage (HDFS) and batch computation framework (MapReduce)
* **Apache Pig** – High-level procedural dataflow scripting language (Pig Latin) for Hadoop
* **Apache Hive** – Distributed data warehouse software with SQL-like query interface (HiveQL)
* **Apache Spark** – High-performance in-memory distributed compute engine (RDDs, DataFrames, Spark SQL, MLlib)
* **Apache HBase** – Distributed, column-oriented NoSQL database on top of HDFS

---

## Techniques & Methodologies

### Data Engineering & Ingestion
* **Data Collection** – API data ingestion, web scraping, and multi-format data acquisition
* **Data Cleaning** – Null/missing value imputation, schema standardization, type coercion, and outlier treatment
* **Data Integration** – Record linkage, entity resolution, deduplication, and relational joins

### Data Visualization & Visual Analytics
* **Foundational Data Visualization** – Graphical marks, visual channels, and visual encoding design
* **Visualization Diagnostics** – Fixing common visual issues, eliminating chart junk, scale correction, and overplotting mitigation
* **Interactive Web Visualization** – Data-driven DOM manipulation, dynamic binding (enter/update/exit), filtering, brushing, and transitions
* **Visual Evaluation for Machine Learning** – ROC curves, Precision-Recall curves, confusion matrices, and decision boundary visualization

### Machine Learning & Algorithms
* **Supervised Classification** – Classification algorithms (Decision Trees, SVM, Logistic Regression, Naive Bayes) and model evaluation
* **Unsupervised Clustering** – Partitioning methods (k-Means) and density/hierarchical clustering
* **Ensemble Methods** – Bagging (Random Forests) and Boosting (AdaBoost, Gradient Boosting)
* **Graph Analytics** – Network graph modeling, traversal algorithms, centrality measures (PageRank, Betweenness), and community detection

### Scalable Computing
* **Distributed Batch Processing** – MapReduce parallel computation paradigms
* **In-Memory Distributed Processing** – Resilient Distributed Datasets (RDDs) and DAG execution
* **Out-of-Core Computing** – Scaling up algorithms with virtual memory, memory-mapped files (mmap), and external memory algorithms
